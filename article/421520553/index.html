用于视觉问题回答和视觉定位的多模态紧凑双线性融合

首先，这里有一个论文的链接。我选择评论这篇，是因为它在视觉问题回答和视觉接地任务上取得了最先进的成果，就人工智能数据集而言，这只是一般般啦。

Big question

我们如何才能最好地确定图像的突出区域并回答有关问题？

背景摘要

我们可以用卷积网创建良好的图像表征，用RNN创建良好的短语和句子表征，因此，"视觉问题回答"（VQA）任务或 "视觉定位 "任务应涉及以某种方式结合这些表征，这是合理的。典型的方法是使用向量连接、元素向量相加或元素向量相乘来结合这些表示。作者怀疑这些方法过于简单，不能完全捕捉到图像和文本之间的关系（有道理），但不愿意使用双线性集合（又称向量的全外积），因为所产生的参数数量太多，不实用（在这种情况下，我们的图像和文本向量的长度为2048，所以产生的矩阵将有2048²个元素，然后用该矩阵做一个3000个类的分类任务，会导致约125亿个可学习参数）。作者在这里应用了一种现有的技术，只用几千个参数（16k）就能捕捉到双线性聚合的判别能力，即多模态紧凑双线性聚合（MCB）的技术。

我有一个理论，"多模态紧凑双线性聚合 "这个术语是专门为最大限度地提高这篇论文的印象而选择的。这是一个口号，但并不是一个多么复杂的概念。"双线性聚合 "简单地说就是两个输入矢量的外积；当你把一个长度为N的矢量的每个元素与另一个长度为M的矢量的每个元素相乘时，就会发生这种情况，从而形成一个大小为NxM的矩阵。这就产生了大量的参数，使其功能强大但非常昂贵。紧凑的 "双线性聚合 "意味着作者应用了降维技术，以较少的参数获得几乎相同水平的能力。我不知道它是如何工作的--我没有读过发明紧凑双线性聚合的论文--但我不知道这如何能在训练过程中改变参数。在我的脑子里，我想象的是类似于主成分分析的东西。就我所知，"多模态 "是一个描述这个特定用例的术语，但实际上并没有什么不同的意思--紧凑双线性集合可以在任何两个向量上进行，实际上，一个向量恰好代表一种模式（图像）而另一个代表另一种模式（文本），这一点都不重要。

具体问题

我们能否通过这种巧妙的双线性聚合方法来提高视觉问题回答和视觉定位任务的性能呢？

方法

作者开发了一个模型，在需要结合视觉和文字表征的三个不同点上使用MCB。

1. 预测图像中的空间注意力

2. 预测问题的答案

3. 将编码的多选题答案与问题+图像的组合空间联系起来（这只适用于多选题）。

他们还使用了注意力图和额外的训练数据，这感觉有点像牺牲实验的纯度来达到最先进的结果。

方法

> 比如，是2048维的向量，还是有2048个元素的向量，其中每个元素有3000维？这是一个2048维的向量，一个3000维的向量，还是一个6,144,000维的向量？我们为什么不把这个东西叫做矩阵而不是向量呢？? "这里是架构分解。

VQA（Visual question answering）：输入是一张图片和一个问题，输出是3k个类别中的一个。

Wait, the “open-ended” VQA is just a 3,000-way classification problem? Are these answers all one word long? How was this answer set generated — were the answers supplied first, then a set of questions and images created that were answerable by one of the 3,000?

图像表征是用152层的ResNet模型训练的，在ImageNet上进行了预训练。他们没有使用最后的全连接层，而是在倒数第二层的输出（"pool5 "层）上使用L2规范；这输出了2048维的向量。

问题被分词后，进行one-hot encoding，并通过一个学习embedding层，然后是一个2层LSTM，每层输出一个1024维向量，然后拼接起来形成一个2048维向量。

这两部分（图像和问题）通过一个16000维的MCB，再用全连接层预测3000个答案。

Attention和视觉定位：输入是一个短语和一个图像，输出是一组边界框。我需要读一两篇这些论文来理解这一点。

1. Xu et al., 2015 “Show, attend and tell: Neural image caption generation with visual attention”

2. Xu and Saenko, 2016: “Ask, attend and answer: Exploring question-guided spa- tial attention for visual question answering”

3. Yang et al., 2015: “Stacked attention networks for image question answering”

但我还是要试着解释一下这个结果：似乎在卷积网络中的某些层中存在着 "空间网格位置"；该技术依赖于将这些视觉表征与语言表征合并并预测 "注意权重"。论文中还说"Predicting attention maps… allows the model to effectively learn how to attend to salient locations based on both the visual and language representations"。

多选题回答：答案用单词embedding和LSTM层进行编码，LSTM的权重在所有答案中共享。然后，这些答案与MCB合并，并完全连接到N类，其中N是多选答案的数量。

结果

视觉问题回答：比前一年的最先进水平（7.9%）有明显的改进，比今年的第二名竞争模型（<1%）有适度的改进，但这一改进大部分是由于加入了注意图（估计还有一些是由于额外的训练数据）。值得庆幸的是，他们省略了部分模型，所以我们可以看到，MCB在结果中占了大约3%的改进。

视觉定位：在技术水平上有适度的改进：在两个VG数据集上的改进都略低于1%。

作者承认，他们的方法可能比现有技术水平要好，只是因为他们的模型涉及更多的参数。他们通过在非线性集合模型的末尾增加全连接层来补偿这个混杂的变量，直到参数总数相当，然后比较这些模型的性能。但我不知道我是否相信这证明了MCB是赢家，或者它只是证明了在矢量表征结合的地方有更多的参数是差异的制造者。也许一个更好的控制方法是从向量的外积中随机选择维度，使总维度与MCB相同（16,000）？这将表明MCB在向量相遇的地方提供了比随机选择的参数更好的结果。此外，他们怎么知道16,000是向量相遇处的最佳参数数？如果那是信息瓶颈，表示法需要高度复杂才能捕捉到图像和语言之间的关系，那么为什么不在那个位置试验更多或更少的参数呢？

结论

作者试图在比赛中获胜；幸好他们还按技术分解了他们的结果。似乎MCB值得在几乎所有涉及组合相似维度向量的模型中考虑--它比连接、加法或乘法等标准技术更有优势，因为它能捕捉到更多关于多模态表示之间关系的信息。作为一个额外的好处，因为它是基于元素的乘法，任何数量的类似尺寸的向量都可以被有效地添加。

视觉问题回答。如果你的答案已经在3000个单字答案的范围内，你能在回答关于图像的问题的能力上走多远？这能代表有用的普通问题和答案的哪个子集？我不确定。然而，不难看出这是迈向人工智能助手的一步--多久之后我们才会有计算能力来编码不仅仅是3000个简短的答案，而是一个更大的可能答案集，也许其中包含了人们最常见的80%的答案？Alexa或Google Home可能依赖于类似的技术。

另一方面，视觉定位可用于自动清理图像，或用于与视频有关的任务，如在自驾车应用中识别行人或向你示意的另一个司机。改善这里的技术水平显然是有用的。

但更大的原则--如果你相信他们的方法，MCB是结合不同类型信息的卓越方法）对任何混合模式任务都是有用的。

所有这些最棘手的部分是，MCB要求向量是相同的长度。但这可能是不切实际的--想象一下一架自动驾驶飞机，它将来自机翼上的摄像机的视觉数据与不太复杂的仪器--也许是机头上的风传感器--结合起来。最好是你能够有效地结合这些表征（即不使用外积），但又不要求你的风传感器输出像摄像机一样高维的表征。我理解作者为什么选择在VQA任务上测试用MCB结合向量--语言和图像是类似的复杂，所以需要输出类似维度的向量--这是一个完美的应用。一种有效结合不均匀维度的向量的技术将是一个很好的研究点。

我不知道的单词

向量的外积：将两个向量相乘成一个矩阵的别致名称（将向量A的每个元素乘以向量B的每个元素）。[1, 2] ⊗ [3, 4] = [[3, 4], [6, 8]]

卡特尔积：这在技术上是集合理论，但它与外积的概念相似，但你是在创建集合，而不是产品。类似于数据库中的嵌套循环连接算法。[1, 2] × [3, 4] = [[[1, 3], [1, 4]], [[2, 3], [2, 4]]。 (这个符号显示了与外积的对比! ⊗看起来像×和○的组合，这有点像乘法符号)

元素相乘：两个相同长度的向量组成第三个相同长度的向量。[1, 2] x [3, 4] = [3, 8].

Hadamard乘积: 同上!

点积：将两个相同长度的向量进行元素相乘，然后将结果相加。[1, 2] ⋅ [3, 4] = 11.

内积：这是点积的一种更普遍的形式；内积可以在任何两个向量上计算，包括无限或复数（即包括虚数）向量。点积只能在实数的向量上计算。

张量积：只是外积的另一个名字。

交叉积：找到一个垂直于两个给定矢量的矢量。对物理学、工程学和其他很多东西都很有用......但对神经网络就不太适用了 :)

双线性聚合：两个向量的外积的更高级名称。

"无MCB的消融"：通过消融，他们的意思是，他们试图依次从每个位置省略MCB，并用类似的东西来代替它（在这种情况下，矢量连接后有多个总维度相似的全连接层），以测试MCB的额外好处。

视觉定位：找到一个短语在图像中的位置的边界框。

L2归一化：对大的输出进行惩罚；有助于避免爆炸性梯度。
