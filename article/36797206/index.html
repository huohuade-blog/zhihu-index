霍华德：机器学习是一种认识世界的方式

今天，我又遇到一个不一样的问题，我能找到一些学校某些专业的数据，但有些数据怎么也找不到，数据不完全，怎么估计确实数据呢？如图1所示。因此，这个问题就变成了：已知某些学校专业的薪酬，如何未知薪酬呢？

感觉这方程都没法联立啊，这怎么做呢？魔鬼就藏在数据中。首先，看学校，清华北大上交同一专业的收入是不是有差别呢？这是学校带来的差异。再看专业，同一学校，不同专业是不是有所不同，这是专业带来的差异。如果我们能对学校和专业的差异建模，那么似乎我们就有办法猜出缺失的数据。

那怎么估计出学校和专业的差异呢？


思路1： 矩阵分解成专业矩阵和学校矩阵

用奇异值分解（SVD）把我们的矩阵A分解成U->学校矩阵， V->专业矩阵，还有 奇异值矩阵。学校矩阵的每一行代表一个学校的特点，这个学校的特点都被概括在向量里了；同理，专业矩阵的一列是一个专业的向量。奇异值矩阵可以简单的理解成特征的重要性。选取最大的K个奇异值对应的特征向量组成的矩阵，然后再乘起来。这个时候，那些缺失值都变成了其他的分数，这个分数就是预估值。

当然，做这些之前，首先要补齐矩阵，残缺的矩阵是无法分解的。一般的方法呢，就是用平均值填入到缺失值里。

先开启上帝视角，我们假设完整的矩阵是这样的：

[[15000, 12000, 10000, 8000],
 [14000, 11000, 9000, 7000],
 [13000, 10000, 8000, 6000]])

然后我们把15000和9000扣掉，设成NaN。好，直接上代码：

matrix_miss = np.array([[np.nan, 12000, 10000, 8000],
          [14000, 11000, np.nan, 7000],
          [13000, 10000, 8000, 6000]])
#calculate the avg value
avg = np.nanmean(matrix_miss)
#repalce the nan with avg
where_is_nan = np.isnan(matrix_miss)
matrix_miss[where_is_nan] = 9900
#perform svd 
u, sigma, v = np.linalg.svd(matrix_miss,  full_matrices=False)
sigma_m = np.diag(sigma)
matrix_f = np.dot(np.dot(u,sigma_m),v)

#get top k 
sigma_r = np.diag(sigma[:2])
u_r = u[:,0:2]
v_r = v[:2,:]
matrix_r = np.dot(np.dot(u_r,sigma_r),v_r)

15000估计出的结果是9898.5，9000估计的结果是9571.95。结果呢不大好，估计得值都特别接近平均值。而且SVD分解是个O(n^3)的复杂度，对于大矩阵算的超级慢。

思路2: 用神经网络来学习

既然在SVD分解里我们可以得到专业向量和学校向量，为何我们不知道用随机梯度下降法来学习专业向量和学校向量呢？这样最后学校向量乘以专业向量，不就得到我们想要的估计值了吗？

我们的目标是通过学习已有的数据，来估计学校向量和专业向量。我们用均方误差来做损失函数：

直接上代码：

matrix_miss = np.array([[np.nan, 12000, 10000, 8000],
          [14000, 11000, np.nan, 7000],
          [13000, 10000, 8000, 6000]])

global_avg = np.nanmean(matrix_miss)

where_is_nan = np.isnan(matrix_miss)
matrix_miss[where_is_nan] = 0

#init x with random variable
u = (np.random.random([3,3])+1)*np.sqrt(global_avg/3)
m = (np.random.random([4,3])+1)*np.sqrt(global_avg/3)

#make x varible
u_var = Variable(torch.FloatTensor(u),requires_grad=True)
m_var = Variable(torch.FloatTensor(m),requires_grad=True)

matrix_m = torch.FloatTensor(matrix_miss)

optimizer = torch.optim.SGD([u_var,m_var], lr=0.0001)

for train_step in range(500):
    loss = 0
    for i in range(u_var.size()[0]):
        #print (x_var[i,:])
        for j in range(m_var.size()[0]):
            if matrix_miss[i,j] != 0.0:
                value = matrix_m[i,j]
                loss += (value - torch.dot(u_var[i],m_var[j]))**2

    loss_avg = loss/10

    if train_step % 100 == 0:
        print (loss.data.numpy()[0])
    
    optimizer.zero_grad()   # 清空上一步的残余更新参数值
    loss_avg.backward()         # 误差反向传播, 计算参数更新值
    optimizer.step()
   
print (np.dot(u_var.data.numpy(),m_var.data.numpy().T))

然后我们训练了五百轮，得到了下面的结果。

[14995.14   12000.852   9999.965   7998.7524]
[14000.228  10998.647   8821.045   7001.6777]
[12999.779  10000.463   8000.0454  5999.648 ]

结果，棒棒哒。15000估计值是14995，9000估计的是8821！完美～

之所以写这个例子，是因为在机器学习中有大量这样的问题，如推荐系统。在推荐系统里，对于用户数据可以整理成一个用户-物品矩阵。这个矩阵中含有用户对物品的评分，但也有很多物品用户没有打过评分，就是缺失值。而推荐系统的终极目标就是对用户，预测未评分物品的分值，并按照分数从高到低推荐给用户。而起计算过程就如我两个写到的两个思路。
