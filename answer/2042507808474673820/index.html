LinearAttention在KV cache的存储上有多大优势？

momo · 发布：2026-05-25T23:30:09+00:00 · 更新：2026-05-25T23:31:27+00:00

这个我最熟了。就以 RWKV7 为例，RWKV7 的 state 相当于 32 个 kv cache，这当然是标准的 MHA 的 kv cache，会存下来一个 key 和一个 value。

所以可以简单认为，对于 MHA，只要你的序列长度超过 32。使用RWKV 就会在 kv cache 上有存储优势。

当然，随着现在各种新架构的不断改进，使用的 kv cache也越来越小。例如 Deepseek v4 用的就是 shared key value MQA。像这样它每个 token 只存储一个向量，这个向量是 key 和 value 共享的。并且 MQA 假设它原本有 8 个头，只保留一个头吧。那么这样 RWKV-7的 state 就会相当于32x 2x8=512 个kv cache。
