请问如何不使用 Python 等工具找出英文文档中出现次数最多的单词？

霍华德 · 发布：2018-03-21T14:53:34+00:00 · 更新：2018-03-21T14:55:39+00:00

查看知乎原文

来个shell一行流，工科生就是这么傲骄：

tr 'A-Z' 'a-z' < SomeText.txt|tr –sc 'A-Za-z' '\n'|sort|uniq –c|sort –nr|head -1
