是时候，找到我做的一张PPT了。不说gate，因为gate是个很宽泛的概念，这里说decay，特指相当于RWKV里W的那个参数。这个W参数，基本在各种Linear Attention里都有等价物。

  1. S4是static decay，Mamba-1是dynamic S4。
  2. Mamba-2走回了linear attention路线，改成了head-wise dynamic decay。
  3. RetNet是head-wise static decay，Mamba-2可能有参考RetNet的思路。
  4. RWKV-6是channel-wise dynamic decay，是当时（24年）表达力最高的设计。
  5. 所以回答你的问题，改这个decay在过去一段时间，实际上就是Linear Attention发展的主线。
