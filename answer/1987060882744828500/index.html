我觉得是分配机制导致的

一个粗糙的模型：

美国印钞化债 -> 直接发钱 或者 提高劳动者收入 -> 消费增长 -> 消费股营收和利润增长 -> 股价上涨（如沃尔玛）-> 标普500 / 纳指上涨 -> 全民受益（大多数人的养老金也在股市里）

这里面链条里，直接发钱，美国人就狠狠消费，不会存起来。

另外，完全都是美元计价的，不断印钞，货币总量膨胀。
