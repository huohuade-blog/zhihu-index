如何评价Kimi Linear？

delta rule这一系列最早的idea可以追溯到Widrow-Hoff规则。

最早意识到线性注意力和delta rule关系的是schlag的《Linear Transformers Are Secretly Fast Weight Programmers》

最先做出高效实现版本的是DeltaNet（Parallelizing Linear Transformers with the Delta Rule over Sequence Length）

小参数设计的极致优化版是RWKV-7（RWKV-7 "Goose" with Expressive Dynamic State Evolution），每一个小参数的设计背后都有大量的消融实验，迭代了N个版本后才有了现在的形式。当然这也被质疑，怎么那么多小参数，怎么冒出来没办法全都说得清，因为不是rational design的，而是演化出来的。
