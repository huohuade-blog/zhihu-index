* This module provides a BLAS optimized matrix multiply, * inner product and dot for numpy arrays：cblas内核函数

你会发现np.dot就是分类讨论式的使用blas函数，先判断好你输入的数据类型，是标量，一维向量，还是矩阵，然后再调用相应的blas函数。
