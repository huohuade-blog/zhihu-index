随着科研的不断全面深入，创新点会不会枯竭？

这世界上重大且做不动的问题可多了去了

创新，亮点是发论文的关键，但是，随着科研人员数量的暴增，创新点会不会不断地减少，直至枯竭，怎么想也想不到前人没做过的东西了。

这属于常见误区了，根本在于很多人也没有搞清楚科研的本质是什么？

按照我的科研路标理论就很好解释。科研工作者真正的使命是发现人类历史上重要的路标，指引人类迈向未知的“新大陆”。

从这个角度，别人做没做过一个问题，一点都不重要。毕竟别人做过的，无关紧要的东西可太多了。单纯找一个前人从来没有做过的组合式创新，那也是非常容易的。先做A + B，A + B做过了，就做A + B + C， A + B + C做过了，就做A + B + C + D，可以无限加下去。材料领域的炒菜科研不就这样，缺少创新点吗？不缺，但重要的吗？根本不重要。
