不同公司的 Token 品质不一样，那怎么对比性价比？

momo · 发布：2026-05-31T14:49:37+00:00 · 更新：2026-05-31T14:50:40+00:00

查看知乎原文

不同公司的 token 确实代表的含义不一样。

简单说，词表越大， 生成相同长度的文本，所需要的 token 越少。

实际上性价比我觉得并不难比，毕竟成本你是知道的，对吧？

关键是如何评价效益？

一个思路就是用能完成的任务的效益作为 token 的效益。

比如说一个 Debug 任务，需要之前传统程序员三天的工作量。假设就算一个程序员 1/10 的月工资吧。假设就是这个程序员月薪 3 万吧，那么这个任务就值 3000 块钱。

然后你就调用不同的大模型 API，在能完成的基础上，再看它们这些 token 消耗的消耗量。

一个任务的成本就等于消耗的 token 量乘以单个 token 的价格。

再用这个任务的收益除一下这个任务的成本，不就得到性价比了？
