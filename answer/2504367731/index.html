开始正题前，先给大家降维一下，帮助大家更好的理解英特尔所说的四大超级力量：人工智能，无所不在的计算，无处不在的连接，从云到边缘的基础设施。施瓦辛格有一部经典电影《终结者-天网》。电影中的天网Skynet是美国军方研发的一款人工智能（AI）主要是为了保护人类的安全，预防犯罪。天网使用的AI云计算把大量从各个渠道采集到的信息和数据搬到了云平台进行分析和预测。这里面涉及的就是云平台及其实体数据中心，相当于《终结者--天网》里的那栋大楼。人工智能那大家基本上耳熟能详了，人工智能指的是一类算法，让电脑模拟人类的思考方式也就是电影里的那个天网。万物互联和云到边缘的基础设施这两个是不可分的，我们就可以理解为是网络硬件设施和智能终端设施。网络硬件设施就是我们常用的比如5G网络信号塔，铺设的光缆，还有各个信号基站以及各种专用网络。智能终端，就是我们用户常常接触到的，比如智能音箱，智能扫地机这种执行命令的设备，电影里面的话就相当于那些机器人了。

云架构正在经历前所未有的巨大变迁

十年前，我们还在讨论云是什么，要不要上云。过去十年世界快速云化，越来越多的服务和生意来到了云端。

而现在，我们又站到了新时代的起点，告诉大家一个惊人的事实，地球上的数据正在爆发性增长，2021年的数据量大约80ZB（8x10^13 GB），到2025年将暴增了到180ZB。这使得云架构正在经历大量的工作模式和关系模型转变， 传统的中心化的云平台已经很难满足要求了，云架构正在从完全中心化的模式向混合模式转变。一种混合模式是公有云和私有云的混合部署，称为混合云Hybrid-Cloud。另一种混合模式是使用多家厂商的公有云或私有云，称为多云Multi-Cloud。还有一种更加具有挑战性的混合模式，公有云、私有云和边缘设备（手机、IPAD等）共存的混合模式，称为分布式云Distributed-Dloud。在分布式云环境下，计算负载也将在边缘设备和云端之间迅速迁移，使得资源成本的控制、低延迟数据访问及数据安全成为了全新的挑战。

为了应对云架构变迁的巨大挑战，英特尔勇于创新，积极给出了自己的解决方案。

第四代英特尔® 至强® 可扩展处理器 （代号Sapphire Rapids）

本次峰会展示的新产品中，代号为Sapphire Rapids的第四代英特尔® 至强® 可扩展处理器非常亮眼。面对云架构发展的巨大调整，底层算力的支持和优化显得愈发重要。而Sapphire Rapids就在扮演这样重要的角色。

具体有哪些亮点呢？

1. 集成英特尔深度学习加速技术（Intel DL boost）更加强大的通用矩阵乘法GEMM，更好的支持人工智能推理。这在人工智能应用中至关重要。

2. 集成英特尔® 通信加速技术（Intel® QAT），有助于提升服务器的吞吐量。

3. 采用英特尔数据流加速器，以支持更高效的数据移动，提升数据在云平台和边缘设备上的移动效率。

借助至强® 可扩展处理器上的这些优化，英特尔为客户释放更多处理器资源，不断提升计算性能，帮助客户实现更高效的工作负载优化。结合英特尔完整的产品组合，再借助参考架构和开放软件工具套件，能够和客户共同构建优化的解决方案，一同应对云架构变迁的挑战。

云架构的变迁，对人工智能的运维MLOps和人工智能算法的部署同样带来了全新的挑战，我们将在下一个人工智能章节一起来谈。

Granulate实时资源管理优化

如何在优化成本的基础上分析和应对近似于实时或实时的数据呢？英特尔给出的解决方案就是Granulate-1个星期前英特尔刚刚收购了这家软件公司。Granulate 能够提供基于人工智能的实时持续优化软件，在操作系统层面帮助客户实时优化资源管理。借助Granulate，公司可以通过降低基础设施和云的成本来提高业务成效，而不需要修改任何代码。

在我看来Granulate更接近一个智能运维软件，通过实时监控实例中数据流的资源使用情况和处理过程，它会针对热点服务进行调度优化和优先级优化，保证热点服务有足够的资源，又保证冷门服务不会浪费过度资源。 Granulate在Coralogix公司落地后，资源占用率降低30%， 服务成本降低45%，CPU使用率提高了15%。

人工智能（AI）进入新纪元

人工智能话题在英特尔On产业创新峰会上遍布各个会场，我整理成一个统一的章节，帮助大家更容易了解英特尔在AI上做了哪些重要的事情。

人工智能进入大模型新纪元， 随着大模型在人工智能领域的快速发展，大家越来越发现大量数据+大模型成为一种可快速解决问题的路径。训练和使用大模型的瓶颈主要在于算力，为此英特尔推出了全新的深度学习训练处理器和推理处理器。

可用于数据中心和云端的深度学习训练芯片Gaudi 2和推理芯片Greco

首先，作为深度学习炼丹师，我最为exciting的就是看到英特尔推出了第二代深度学习训练芯片Gaudi®2和Greco。这一代AI芯片制程直接从从16nm杀到7nm，和A100芯片的制程齐平。终于不再吃制程亏的英特尔，一下子就体现出了其强悍的芯片设计能力。这代Gaudi 2芯片具有24个张量处理器核心，是上一代的三倍。板载内存也增加三倍，达到96GB，高速缓存也直接翻倍到48MB。这些都使得Gaudi2的性能相比上一代有了质的飞越。

敢不敢来跑一波分？那是必须敢。当今，人工智能有两大最为闪耀的领域 - 计算机视觉和自然语言处理，其背后都有代表性的神经网络架构。何恺明提出的残差网络ResNet，一代经典结构，直接都是很多计算机视觉任务的核心backbone。谷歌的BERT模型，一经提出就风靡全球，成为自然语言处理的新一代王者。而英特尔Habana实验室展示的Gaudi2在ResNet-50计算机视觉模型上的训练吞吐量性能和在BERT自然语言处理模型上的训练吞吐性能，达到了前一代人工智能训练王者芯片的两倍【1】

英特尔最新的这一代大哥Gaudi 2进步巨大，小弟Greco推理卡也表现不俗，同样使用7nm工艺，提供204GB/s的 LPDDR5内存和128MB的片上高速缓存，同时支持媒体解码和BF16、FP16和INT4浮点数格式，目测会成为不错的性价比之选。

复杂云环境下的人工智能工程化（MLOps）

此外，我有一种感受越来越强烈，人工智能也许快结束刀耕火种的时代了。刀耕火种是指完全手工训练模型、部署模型和运维模型的方式。谷歌把其称为人工智能工程化1.0时代。

顾名思义，就是完全通过手工操作实现提供端到端的机器学习能力。基本流程为：

  • 模型训练： 数据科学家通过交互性代码等，人工执行数据探索、数据准备、模型训练和验证等每个步骤，并手动把各个步骤串接成工作流，不断实验评估模型效果，直到训练出来有效模型，把模型打包为序列化模型文件或docker镜像，推送到模型仓库。
  • 模型部署： 开发人员从模型仓库中拉取、加载模型，封装为RestFul API等或边缘部署，对外提供预测能力。
  • 应用开发： 开发人员在第三方应用中调用模型API，获取AI能力。

这样显然是没有竞争力的人工智能工程化模式，特别在复杂云环境下，人工智能工程化还面临着以下几个挑战：1. 边缘到云的协同，训练在云端、部署在边缘设备、监控在边缘设备、运维在云端。 2. 人工智能部署是个异质过程，大量异构硬件会参与计算 3. 手工部署的风险很大，环境管理困难。

英特尔为此专门为客户配备了复杂云环境下的人工智能工程化平台http://Cnvrg.io，一个简化、流程化，也更高效的端到端人工智能平台。主要的特点有这么几个：

  • 帮助算法工程师及数据科学家快速扩展实验，优化性能，轻松并行1000+个实验，快速练出“金丹”
  • 自动化线上部署和自动化离线数据批处理，轻松扩容，帮助算法工程师应对各种业务需求。
  • 天然支持混合云模型，支持开发者利用本地和云资源，同时利用CPU、HPU（全息处理器【2】）和GPU算力。

现在很多公司的算法工程师们都面临一个问题，就是开发完算法后需要依赖后端工程师去做部署，这样算法工程师就失去了对模型部署时间、地点和方式的控制，这会导致在很多公司中的工作效率的低下。使用http://Cnvrg.io后， 就可以无缝地实现模型的训练和部署，从而彻底消除部署上的“瓶颈”。

数据安全

前面我们提到了云平台，AI训练，这其中不可忽视的就是安全问题。相信有过训练AI/ML模型经验的朋友们都清楚，受限于终端设备的算力，很多时候开发人员用的是云计算平台去做模型训练。在这过程当中，数据安全是一个考量的问题。大多数情况下，平台是个多用户的开放环境，数据在存储，传输或者训练时，每个环节都有可能泄露数据。尤其是一些敏感行业，比如银行业，或者其他工业领域。这些行业的数据都是高度机密，一旦泄露后果不堪设想。在此次峰会中，博世负责人介绍了一个自己的研究项目。博世在其自动驾驶的模型训练中，使用到大量的真实数据。一旦这些数据泄露，那么面临的就是巨额罚款。所以要怎么保证这些数据在训练过程当中的安全，是研发团队的一个重要考量。研发团队通过使用Intel® SGX，保证了数据在云平台训练时的安全。同时这种解决方案也是一个相对省钱省力的方案。

Intel® Software Guard Extensions （SGX）加密云计算

Intel® SGX 是什么？Intel® SGX （英特尔® 软件防护扩展）其实是一组安全相关的指令被内置于一些新型的 Intel CPU中。因此这个加密是硬件级别的加密。 这些指令允许用户将特定内存区域设为私有区域，也就是创建硬件安全飞地，并在此区域将特定程序的数据进行本地加密。这样的话，处于此内存区域外的任何进程都无法读取受保护的代码。相当于给特定训练的模型开了一个单独的房间，进行计算。下图是SGX的使用比较【3】。

除了博世，还有一些我们耳熟能祥的国产大厂也都在使用英特尔的这项技术。
