自然语言处理中如何在短文本中进行内容过滤？

来来来，手把手送干货了。

1.找/准备一份场景相似的数据集

你问题中提到的是问题-求助，我简单就理解为问答模式了，那么第一步就是找\准备一份问答数据集，如百度推出的中文问答数据集WebQA:

百度的中文问答数据集WebQA 密码: 6fbf

2. 用问题和答案组成"问题-答案对"

把数据集里的问题和答案配对，并抽取他们的配对特征，如tf-idf相似度，词向量相似度，标题n-gram相似度，句向量相似度等等。

更有效的是直接用QA数据训练一个相似度计算模型，这方面深度学习的进展如火如荼，你可以参考一下中科院提出的文本匹配开源工具MatchZoo：

NTMC-Community/MatchZoo

同时，可以随机抽取不相关答案与问题组成负例。想更有效一些，可以做一下hard example mining，把那些用简单相似度解决不了的例子抽出来，人工整理为负例。

3. 训练一个"问题-答案对"的相关性分类器

用上面准备好的数据训练一个二分类器，简单就是判断，问题-答案是否相关。你可以尝试各种模型啦，但在小数据下强烈推荐SVM。SVM的泛化能力真心强。数据比较多的话，可以试试深度学习。

4. 垃圾内容过滤器

"问题-答案对"的相关性分类器训练好之后，可以用使用了。对输入的文本进行分句或分段，看你的实际场景。然后一一和问题组成"问题-答案对"，然后用分类器对其进行分类，如果是相关的，就保留，是不相关的，就过滤。
