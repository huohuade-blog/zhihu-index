深度学习神经网络对于尺寸不同的图片如何处理？resize？crop？

图片预处理对模型效果影响是巨大的，而且根据任务不用，预处理的方式也会不同。这里分享几个办法吧。以下方法，均基于PIL实现。

from PIL import Image, ImageChops
  1. 中心裁剪center crop：先比较长边和短边，以短边为边长从图片中心裁剪出一个正方形。
def center_crop_obj_arr(im):
    iw, ih = im.size
    if iw > ih:
        left = iw // 2 - ih // 2
        right = iw // 2 + ih // 2
        top = 0
        bottom = ih
    else:
        left = 0
        right = iw
        top = ih // 2 - iw // 2
        bottom = ih // 2 + iw // 2
    im = im.crop((left, top, right, bottom))
    return im

2. 四周填充：先比较长边和短边，以长边为边长，对图片周围进行填充，从而得到一个带黑边的正方形。

def expand2square(pil_img, background_color):
    width, height = pil_img.size
    if width == height:
        return pil_img
    elif width > height:
        result = Image.new(pil_img.mode, (width, width), background_color)
        result.paste(pil_img, (0, (width - height) // 2))
        return result
    else:
        result = Image.new(pil_img.mode, (height, height), background_color)
        result.paste(pil_img, ((height - width) // 2, 0))
        return result

3. 三重裁剪three crop：类比pytorch里的fivecrop和tencrop，从图片中裁剪左中右（横屏）或者上中下（竖屏）三个正方形图片

def three_crop(im):
    '''
    three crop
    '''

    width, height = im.size
    if width > height:
        center_img_left = width // 2 - height // 2
        center_img_right = width // 2 + height // 2
        center_img_top = 0
        center_img_bottom = height
        center_img = im.crop((center_img_left, center_img_top,
                              center_img_right, center_img_bottom))
        left_img_left = 0
        left_img_right = height
        left_img_top = 0
        left_img_bottom = height
        left_img = im.crop((left_img_left, left_img_top,
                            left_img_right, left_img_bottom))
        right_img_left = width - height
        right_img_right = width
        right_img_top = 0
        right_img_bottom = height
        right_img = im.crop((right_img_left, right_img_top,
                             right_img_right, right_img_bottom))
        return left_img, center_img, right_img
    else:
        center_img_left = 0
        center_img_right = width
        center_img_top = height // 2 - width // 2
        center_img_bottom = height // 2 + width // 2
        center_img = im.crop((center_img_left, center_img_top,
                              center_img_right, center_img_bottom))
        top_img_left = 0
        top_img_right = width
        top_img_top = 0
        top_img_bottom = width
        top_img = im.crop((top_img_left, top_img_top,
                           top_img_right, top_img_bottom))
        bottom_img_left = 0
        bottom_img_right = width
        bottom_img_top = height - width
        bottom_img_bottom = height
        bottom_img = im.crop([bottom_img_left, bottom_img_top,
                              bottom_img_right, bottom_img_bottom])

        return top_img, center_img, bottom_img
