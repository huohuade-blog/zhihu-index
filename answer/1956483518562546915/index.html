每一次科技大爆发是否都是以材料学的突破为基础的？

momo · 发布：2025-09-30T14:20:20+00:00 · 更新：2025-09-30T14:20:20+00:00

查看知乎原文

看这次大模型技术大爆发就知道了，材料学恰恰处于最末端。

传导链路是这样的：

数字需求 → 算力爆发 → 数据中心扩张 → 能源与散热升级 → 材料革新

【模型突破】
OpenAI、Anthropic 等公司的模型性能爆炸
→ 市场对更大规模、更高质量的模型训练与推理需求骤增
→ 算力需求全面激活
    ↓
【算力芯片】
GPU（NVIDIA H100/B200 等）、AI专用芯片需求陡然上升
→ 带动芯片设计、台积电/三星等晶圆代工、先进封装、HBM 高带宽存储需求
    ↓
【数据中心】
云厂商（AWS、Azure、Google Cloud）以及本土算力平台大量扩建超算中心
→ 服务器、机柜、交换机、电源管理系统需求上升
→ 存储需求扩大：SSD、磁带、分布式存储架构
    ↓
【能源系统】
单个数据中心功耗达百兆瓦级
→ 火电、燃气轮机、核电、小型模块化反应堆（SMR）扩张
→ 可再生能源（风电、光伏、储能）加快部署
→ 电网层面：特高压输电、本地配电网络升级
    ↓
【散热与电力支撑】
传统风冷不足 → 液冷、浸没式冷却、热交换系统大规模应用
→ 电力设备：变压器、特高压输电线缆
→ 高导热材料：铜、碳化硅、氮化硅
→ 电力材料：超导材料、绝缘材料
→ 工程材料：耐腐蚀合金、冷却液专用化工品
    ↓
【进一步的“材料末端效应”】
当散热、电力、能源产业升级时，最终都回落到材料层：
半导体 → 光刻胶、硅片、EUV 工艺材料。
散热 → 高性能金属（铜、铝）、新型复合材料。
能源 → 核电燃料（铀）、涡轮叶片合金。
储能 → 锂、钠、钒电池材料。
