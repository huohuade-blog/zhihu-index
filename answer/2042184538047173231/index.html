如何评价deepseek v4 pro模型再次永久降价至四分之一？

我下面说的话可能会被喷，但我还是想说出的。

Deepseek V4 因为极其创新的架构设计，其 Token 成本确实应该是全世界最低的。

但与之相反， anthropic 的 Token 从不降价，应该是全世界最贵的。为此我还专门提了一个问题，Anthropic 是不是还在用最保守的架构，即多头注意力 MHA 加上稠密的MLP？

如果是真的，那么 Anthropic 确实没有多少降价空间，它的Token推理成本本身就非常高。

但是，极致的稀疏注意力设计也让大家观察到越来越多 Deepseek V4 的 bad case。

其中一个例子是这样的。有人的简历是勘查技术与工程专业，但是被 Deepseek V4 输出之后，变成了勘察技术与工程专业。

勘察和勘查两个词在向量空间里，绝对是非常相近的。对于现有的神经网络而言，本身就不易区分，容易产生幻觉。Deepseek V4 的HCA会非常激进地对一个片段整体做平均，我没有记错的话，应该是 128 个 Token 平均。这就会对原本的词向量产生扰动。使得原本输入的是勘查的词向量，向勘察产生了一点点偏移。进而引发了幻觉。

以上就是我对 Deepseek V4 幻觉更严重的一点点机制分析。进而我就在思考，一个 Token 上所携带的计算量是否有 lower bound？当每个 Token 的计算量少于某一个值之后，就会引发一些不确定性的风险。

当然，我觉得这是很不好说的。所以就回到前面 Anthropic 的疑问。我怀疑 Anthropic 之所以这样保留最慢的架构、计算量最大的架构、效率最低的架构，实际上是一种冗余设计。

既然不知道每个 Token 到底最少需要的计算量是多少，那就干脆多给它一点吧。尽量保证效果最优。至少在很多场景下，有冗余还是好于没有冗余。
