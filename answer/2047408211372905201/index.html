领导说AI会淘汰大部分程序员，到时企业只需一两个架构师就能完成所有项目，这是危言耸听还是真的会发生？

Cursor最近发了个开发者习惯报告2026，我觉得相当好。提供了很多量化后的指标，可以定量比较很多趋势的演变。

其中最震撼的是top1%的开发者使用的token数量是中位数的46倍，提交的PR数量是中位数的15倍。纸面上看，1个top1%程序员可以顶46个普通程序员。

据我的观察，Top 1% 的开发者之所以能使用那么多的 token，很大一个原因是他们是喜欢从头用多 Agent 构建一些项目来做一个事情。像我看到的李博杰一个人就用一个 Agent 完成了一篇 76 页的论文。而相反，一些项目是在屎山上修修改改，效率根本提不起来。很多时候， code agent 的对项目的理解还是有问题，做的很多修改都是错的，还是要人为引入大量的指导和修正。这样的话， token 的使用量、PR 的推送量都会小得多。我觉得这个里面最重要一点还是，到底是什么样的任务？这个就我觉得差异还是很大的。
